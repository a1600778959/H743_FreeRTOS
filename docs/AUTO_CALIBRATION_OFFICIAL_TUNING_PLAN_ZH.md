# 按 PX4 官方方法实现三项导航参数标定的计划

日期：2026-09-24。状态：按最终确认计划实施，以下记录当前实现；原始规划细节保留供追溯，冲突处以本节为准。

## 当前实现与物理条件复核（2026-09-24）

复用 `update_segment`、PurePursuit、Heading、Driving 和公共速度/角速度内环。`segment_arrival_speed` 与 `update_waypoint_progress` 是从 AutoMode 提取的唯一共享实现。校准只组织实验、观测、候选和原有 RAM 事务，不发布电机脉宽、不处理反向、不创建影子导航。初始直线零转向及后端满输出持续大于3秒制动保持不变。

本轮针对已实现的三项方法继续修复了下列问题；本节优先于后面的历史计划。

| 项目 | 原问题与物理原因 | 当前实现 |
|---|---|---|
| PP低速工况 | 半最大速度可能落入现有控制死区，不能由此判定低速车不可校准 | 半速不可运行时采用本轮最低可运行实测平台；不修改死区，不猜测速度折扣 |
| PP可辨识区间 | MIN/MAX钳位或前视圆大于整段时，增益变化不一定改变路径响应 | 搜索范围同时受合法参数、MIN/MAX及实际直线长度约束；原值不可观测不阻止其他有效候选，低速钳位不假报增益已辨识 |
| jerk初始化 | 临时种子误作物理下界；已有正jerk也受种子计算阻挡 | 仅禁用初值才反解种子；扣除两端到达区域、建速距离和已验证一阶模型到90%的建速时间对应距离，再使用PX4公式。空间不足可改用本轮较低实测平台；种子不是搜索下界 |
| jerk评分 | 慢爬能降低jerk RMS，却没有完成规定速度工况 | 独立jerk试验先真实达到固定巡航再观察制动，各条边均须有制动证据；最终组合方形允许生产规划自然降速，但仍逐边观察制动 |
| jerk观测 | RTK天线速度二次差分混入杆臂转动，先差分再投影遗漏旋转基变化 | 直接使用已有EKF车辆参考点NED加速度，逐历元计算 `a_forward=ax*cos(heading)+ay*sin(heading)`，再以真实dt求导；删除导航私有0.5秒滤波器，复用EKF滤波及200ms失鲜合同 |
| RED能力来源 | 达到用户巡航上限仅证明能力不低于该速度，不能用等式反解能力极限 | 明确实跑合法上界；上界通过的方向是删失观测，不参加等式反解。两方向均未测到失败边界时恢复原系数并报告不可辨识 |
| RED有效转弯 | 只在中心航点取一拍速度，后续可能停住/原转；终点制动也可能污染能力结果 | 使用入口—中心—出弯观测点—独立停车点四点路径，中心至出弯点持续观察Driving、平移和局部跟踪误差；停止腿失败不能建立转弯速度上界 |
| RED角度与最终范围 | 极小角度放大反解误差；单一角度通过不能证明大角度合理 | 试验角取现有转驱滞回区间中点，这是本地实验几何选择，不修改门限。局部航点y向右，正转角为NED右转，修正原左右标签对调。最终复核方形、中角左右、进入原转阈值角左右共五条路线；大角度允许公共导航根据实际误差停车/原转 |
| 瞬态及数据归属 | 一拍限斜率否决整轮；旧航段反馈可能归到新航段 | 真实运动数据保留，未受遮蔽的样本才证明参数生效；按现有request_sequence区分新旧航段并处理回绕；近零刻意停车/旋转不参加相对速度评分 |
| 观测不足与超时 | 遮蔽、缺测或停止腿失败被当成转弯能力不足，会错误收缩区间 | 观测不足不进入搜索收缩；超时归为未完成。单腿截止为原75秒与几何/速度/加减速/jerk/航向模型预算的较大值，不增加会话总时限 |

### 判据的职责边界

- `RO_CAL_XTE_MAX` 表示用户指定的路径性能目标，默认0.20m且会话冻结；不是RTK质量阈值。超过它只结束当前候选并受控停车。实验到达半径取它与 `NAV_ACC_RAD` 的较小值，防止方形换边产生必然超差。
- 速度/角速度跟踪使用已有内环10%口径与近零轴既有死区；饱和标志本身不判失败。不增加两向能力对称性、精度噪声倍数、峰值jerk或参数折扣门。
- 真实围栏、失鲜、Kill、参数代次、受控停车和存储失败仍由现有安全/事务链处理。本轮没有删除公共估计器或传感器质量条件。
- 搜索分辨率0.01仅用于数值结束。PP/jerk使用固定容量黄金分割，RED能力使用有界二分；未知数据不被当作“不通过”。搜索不是任意路面下全局最优保证，转弯能力指本轮控制器、场地和路径精度目标下的已验证能力。
- PP按横向RMS优先、实际角加速度RMS其次；jerk在跟踪合格后按实测jerk RMS优先、速度RMS其次。测到的是水平纵向加速度变化，不是机械最大jerk或三轴乘坐舒适性指标。每条制动腿至少一个有效差分间隔是最小观测要求，其统计分辨能力仍须实车验证。
- 每项复跑确认，改善不能复现则回退并结束该项；各字段独立结算。最终组合失败清除本组证据并恢复原值。候选恢复也等待真实前端参数代次，不要求原禁用jerk具有导航可运行性。

## 2. 固定边界

1. 正式制动仍由后端确认 `MOT_THR_MAX` 满输出持续大于3秒触发；不恢复等待速度稳态，不改变已定减速度计算。
2. 初始直线制动、速度响应、ARX辨识继续仅纵向激励。下面的路径直线跟踪发生在内环/Heading已通过验证之后，使用生产导航控制器，不能把航向修正加回初始实验。
3. 导航能力优先调用代码库已有函数和方法，不重写导航模块。校准负责实验输入、响应观测、候选参数和事务；导航负责路径跟踪、速度规划、转驱及到点。输出复用 Commander → RoverDifferential → MotorOutput；不处理PWM、REV或模式私有方向补偿，不新增控制器。
4. 一个实验只改变一个待标定参数。其他参数、路径、目标速度、采样定义保持一致。三项分别有证据后才做整组复核。
5. 保留既有传感器/请求/参数代次、围栏、停车、取消、事务与存储责任。性能不理想不伪装成整车故障；真实公共安全故障仍沿现有终止链。
6. 不新建调参框架、测试文件、测试框架或测试基础设施；不手写参数/消息派生列表。必要契约从权威YAML/.msg修改并正式生成。关键算法、控制逻辑及安全边界用中文解释。
7. 不以“PX4没有唯一闭式解”为由取消这三项功能，也不为了宣布完成而生成没有目标依据的数字。

## 3. 当前代码要解决的缺口

- `start_path_validation()` 目前只重用原参数；`finish_path_validation()` 无条件把PATH/NAV标为未完成。需要换成按三个独立证据结算，不能直接删除unavailable位就宣称成功。
- 当前路径只有闭合瘦三角，且 `arrival_speed=0`、每个点都停车；这不能覆盖降速系数的连续过弯作用。生产 `AutoMode::prepare_segment` 已有到达速度逻辑，应复用或提取现有计算，不再复制另一套。
- `prepare_path()` 和生产速度规划要求正jerk，导致jerk禁用时连前视实验都不能开始。将“直线中段跟踪测量”和“航点减速规划”分开：前者不依赖待标定jerk；需要停车的段使用既有正式制动能力。不得用静默正默认值修补这个依赖环。
- 已有 `SegmentGuidanceOutput` 提供实际前视距离、横向偏差、航向误差及规划速度；`RoverControlStatus` 提供实际限斜率后的设定、实测速度/角速度和限制原因。优先使用这些数据，不建立影子导航控制器。

## 4. 三项的实验与计算

### 4.1 PP_LOOKAHD_GAIN：直线跟踪、纠偏和振荡

**官方方法：** 从1开始，以约半最大速度直行；沿线能力不足减小增益，绕线振荡增大增益。低速行为还受PP_LOOKAHD_MIN影响。

实施步骤：

1. 保留原参数作为回退基线；以官方建议1作为首次整定参考，不先持久化覆盖原值。
2. 名义试验速度取本轮实际观测到的前进能力的一半，并受用户RO_SPEED_LIM和实际场地约束。这里的“一半”是官方实验速度，不是对实测速度或参数的折扣。
3. 执行固定直线路径的跟踪段，用同一入口位置/朝向复核候选；纠偏由已验证的生产PurePursuit→Heading→YawRate链实现。
4. 记录实际 `L=clamp(k|v|,Lmin,Lmax)`。若实验全程被MIN/MAX钳住，不再盲改k或伪造有效样本；在已有速度/场地范围内选择能观察k作用的工况。做不到时单独说明限制来源，不否决其他标定项目。
5. 观测带符号横向误差、实际角速度、位置/速度设定跟踪。用真实时长计算横向误差RMS及纠偏过程；识别实际反复越线后误差幅值是衰减还是持续/扩大，不用“请求换向超过12次”等计数冒充振荡。
6. 按官方方向形成单参数候选区间；在实际证据形成相反调整方向后，用区间收缩选择下一候选。候选生成是数值搜索，不是物理公式；禁止把搜索步长转成额外准入门。
7. 找到改善候选后，用相同直线重新执行确认，并复核用户实际低速工况。PP_MIN/MAX仅诊断，不在三项标定中偷偷改写。

**自动判读的本地设计：** 用横向响应的收敛与实际往复幅值描述“跑不直/振荡”，并与速度、角速度内环的跟踪状态分开。正式编码前先用已有/补充实车日志核对能否区分控制振荡、路面扰动和定位抖动。无法区分就报告观测不足，不引入未审查的幅值、次数或3σ常数来强行分类。

**本项完成条件：** 候选确实改变了生效前视距离；同一路径复核支持官方调整方向；没有以变慢、未跑完路径或参数未生效冒充改善。若原值已满足表现，也可确认原值，无须强行制造变化。

### 4.2 RO_JERK_LIM：航点接近时的减速平顺性

**官方方法：** 方形任务观察航点减速；顿挫则减小jerk，无顿挫可增大，并与减速度配合检查。

实施步骤：

1. 使用方形停车航点任务，边长受现有围栏与真实停车能力约束。先固定已测 `RO_DECEL_LIM` 和已确认前视增益，单独改变jerk。不能在每次观察顿挫时同时改减速度。
2. 对齐生产控制器实际采用的速度设定、实测速度、车体纵向加速度及测量历元。只评价靠近航点的减速段，不把原地转向、到点静止或地面冲击混入。
3. `a=dv/dt`、`j=da/dt` 用于描述响应；不把带噪速度二次差分的单点峰值直接写成jerk上限。优先核对现有IMU积分量/姿态/偏置是否足以构造车体纵向运动加速度，重力、杆臂和时间对齐处理复用已有约定；缺少可信观测就不声称自动识别了“顿挫”。
4. 有正jerk原值时从原值开始测量。jerk为禁用值时，候选种子可以从下面的官方轨迹模型反解，但只称为满足该试验几何的规划候选，不称车辆最大jerk：

   `d=(v0²-vf²)/(2a)+2av0/j`

   `j_seed=2av0/[d-(v0²-vf²)/(2a)]`

   这里a是本轮已确认的规划减速度，d是预定的可用减速距离，v0/vf是该段的规划边界速度；实际执行时用实测入口速度复核。分母必须为正，来源是该模型有有限正解的数学条件，不是人为门限。无有限解时调整合法试验几何/速度或报告空间不足，不能截成某个看似合法的jerk。
5. 单参数调整方向遵循官方：出现可确认的减速顿挫则减小；平顺且生产速度跟踪正常时可以增大，以减少过早缓慢减速。使用前视项目同一候选区间机制，不另建重试/缩放规则。
6. jerk确认后复核同一减速度下的停车位置与速度轨迹。若确需更改减速度，回到原有正式制动观测及公式验证，不能为了路径结果把它随手打折。

**公式限度：** 反解来自PX4保守的加速度过渡模型，并非所有路面的精确停车规律；它解决禁用初值和试验几何的初始化，最终仍要按官方方法检查真实减速表现。

**本项完成条件：** 候选在实际规划中生效；实际减速观测支持平顺性判断；到点和速度跟踪经原控制链完成；不是只看规划曲线平滑或单次jerk峰值就保存。

### 4.3 RO_SPEED_RED：航向误差下的降速关系

**官方说明：** `v_limit=V_full*(1-(|eψ|/π)*k_red)`，同时用于根据后续转角计算航点到达速度。官方该页没有提供前两项那样的完整逐步整定流程。

实施步骤：

1. 固定前视增益和jerk，使用生产Driving规则允许连续通过的小转角航段。超过原转驱阈值仍停车/原地转向；不能为了采样放宽该阈值，也不能用原地旋转证明平移降速参数有效。
2. 沿用生产AutoMode对航点到达速度的计算，校准不再所有点强制arrival_speed=0。只在合法连续转弯和真实航向误差区间观察本参数。
3. 先确定独立的目标关系点 `(eψ, v_target)`：来源可以是明确的运行速度要求，或其他参数固定时、已确认跟踪正常的转弯实验。不得把当前降速公式自己产生的速度再喂回去，循环证明它自己正确；目标来源必须记在结果里。
4. 在 `0<|eψ|≤π`、`0≤v_target≤V_full` 且限制公式未被其他钳位覆盖时，按官方关系反解：

   `k_red=π/|eψ|*(1-v_target/V_full)`。

   多个独立目标点可对 `x=|eψ|/π`、`y=1-v_target/V_full` 做过原点最小二乘：`k_red=Σxy/Σx²`。这是上述公式的参数拟合，不把接收机误差改写成速度，也不加入0.6目标比例。
5. 用相同转角重跑，检查实际降速上限、真实速度和生产转驱状态。巡航限速、jerk减速、内环限斜率、输出保护使本项不生效的样本不能证明它已标定；仅记录原因，不再建立一整套影子仿真和3σ差值门。
6. 原值-1表示当前禁用，应保存为基线。由于本任务明确要求标定该项，试验中可以临时应用公式候选；只有独立目标和实跑证据成立后才保存正值，失败恢复-1。

**本项完成条件：** 至少有能定义拟合的独立目标数据；公式候选实际影响过速度限制；生产链上的实车结果验证通过。没有独立目标关系时，明确缺的是设计目标，不声称PX4没有调参方法，也不填默认比例。

## 5. 自动搜索和观测：先把设计说清，再编码

这是最容易重新堆出门限的地方，作为第一项实现任务单独审查：

- 每次仅保存当前参数、基线、候选、候选区间端点及观测摘要，复用现有Prepare/Running/WaitStop/Evaluate与参数事务；不恢复多维候选数组、影子控制器、重复验证状态树。
- 只有官方有明确调整方向的PP/jerk采用方向驱动的区间搜索。形成括区前如何取得下一候选，以及总试验预算，属于本地搜索策略，必须先写出确定规则；不能在代码里临时加入0.8/1.25或随意试遍参数全范围。
- 有括区后取中点收缩区间是数值方法，不宣称PX4规定了这个步长。停止条件使用明确的参数求解精度、有效候选区间耗尽、无可复现改善或已有机动终止条件；不能无限等待。
- 参数元数据increment是显示/编辑步长，不自动等同于物理可辨识精度。求解精度和观测可分辨性分别说明。
- 不把越线次数当振荡、不把裸IMU冲击峰当jerk标定、不把输出饱和本身当控制失败。所有分类保留“数据不足/无法区分”，不强制二选一。
- 搜索策略、PP振荡识别、jerk顿挫识别、RED独立目标来源这四项在编码前形成一张规格表；只允许必要设计自由度，不把每项都扩展成新的用户参数。

## 8. 计划仍需收敛的设计点

官方文档将“振荡”“顿挫”“满意”交给操作者观察，并未给自动判别与搜索步长。因此任务1不是可跳过的形式检查：必须明确可自动识别的响应指标、可靠的数据来源、括区前搜索与预算，以及RED目标速度的独立来源。这些不从官方公式唯一产生，也不应由实现者临时藏进代码。先完成这张规格表，再进入运行期实现；若日志缺少必要观测，精确指出缺什么，不能靠加门限补齐。
