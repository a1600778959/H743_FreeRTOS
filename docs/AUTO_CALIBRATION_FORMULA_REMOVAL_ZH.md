## PI：有来源的公式替换

原文：Sigurd Skogestad, *Simple analytic rules for model reduction and PID controller tuning*, Journal of Process Control 13 (2003), 291–309. DOI: 10.1016/S0959-1524(02)00062-8。

- [作者公开论文](https://skoge.folk.ntnu.no/publications/2003/tuningPID/finalpaper.pdf)，第295页，式(23)(24)。
- [勘误](https://skoge.folk.ntnu.no/publications/2003/tuningPID/correction.pdf)不涉及这两式。

对一阶带延迟模型 `G(s)=K exp(-θs)/(τs+1)`：

```
Kp = τ / [K (λ + θ)]
Ti = min(τ, 4 (λ + θ))
Ki = Kp / Ti
```

λ是设计者指定的期望闭环时间，论文3.4节明确讨论快慢/鲁棒性的取舍。本轮使用原PiDesignLimits设计输入（默认1s），删除暗中的max(3τ,5θ,1s)；默认1s仍是设计选择，不能宣称由车辆实测自动确定。积分时间改为同一套SIMC式，不再将其他规则的τ+θ/2拼入。

辨识与生产控制使用相同归一化轴；有限值、采样时间、模型稳定性、激励、参数合法域及真实闭环验证保留。来源成立不代表任意非线性/地面工况下都可保证通过实车验证。

## 前视增益、jerk、降速系数：已找到的依据与实际限制

正式参考为项目锁定PX4 v1.17 commit `d6f12ad1c4f70ad3230afd7d86e971421e02fef4`：

1. [位置控制调参](https://github.com/PX4/PX4-Autopilot/blob/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/docs/en/config_rover/position_tuning.md)：前视距离`L=k v`，k是调参项；官方要求实跑观察偏离/振荡后调节。此关系不能仅凭v反解唯一k。当前实现输出方位再经Heading与YawRate环，不能直接套直接曲率控制的增益结论。
2. 同一文档给`v_max=V_full*(1-|航迹误差|/π*k)`，k即RO_SPEED_RED。要反求k必须另有给定误差处的目标速度；公式本身没有生成这个目标，更没有给出0.6或0.8种子。
3. [TrajMath.hpp](https://github.com/PX4/PX4-Autopilot/blob/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/lib/mathlib/math/TrajMath.hpp)：jerk限制停车规划以j、a为输入，采用2a/j加速度过渡时间的保守模型。原路径预算中的2vad/j有这个模型出处，不能只看到系数2就认定为拍脑袋。
4. [Ruckig文档](https://github.com/pantor/ruckig#readme)同样将max_jerk作为给定约束；轨迹求解不等同于车辆jerk上限辨识。实测`j=da/dt`也不自动等于允许使用的最大jerk，尤其当前激励包含人为slew。

因此删除现有无依据猜参代码，但本轮没有编造这三项的“唯一公式解”。参数保持原值、保留原路径实跑，现有unavailable状态明确报告STAGE_PATH_GAIN/STAGE_NAV_STRATEGY未完成，已测得并验证的核心参数继续按原事务收尾。用户要求的这三项公式标定仍未完成，不把它们改称已实现。
