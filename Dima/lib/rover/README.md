# Rover 纯算法库

制动响应数学：b为实际两轮负向输出幅值的平均，J=∫b dt，Q=∫b² dt，E为冻结电机包络。以输入加权有效时间T_eff=J²/Q替代含零输出等待的总响应时间；有效响应K=(v0-v1)/(J/E)，归一化制动增益g=Q/[E*J*(v0-v1)]。v1为首次前向停止终点，负向回摆不再扩大速度变化量；输入积分在首次前向停止观测时冻结。该量仍包含地面阻力影响，不是独立力学常数。J=Q=0且真实停车成立时允许g=0，候选须经第二轮停车验证。

第二轮停车时间预算：比例段时间常数为T_eff=J²/Q，不是首轮请求至停稳的总时间。proportional_braking_time按u=min(g*v,1)分段计算饱和恒减速与指数尾所需时间；模式另外计入配置/实测输出等待、电机slew建立时间及既有速度历元/停稳窗留时。预算仅决定何时报告观测超时，不修改制动力、停车速度或观测接受条件。

## 头文件实现边界

纯控制和校准类型的普通访问器与验证实体位于对应源文件；ArxRls 等通用模板保留可见定义，算法字段、求值顺序和六模型状态不变。 统一审查与验收见 docs/HEADER_IMPLEMENTATION_SPLIT_ZH.md。

Manual 电机行为以仓库既定 APM `3f2e4763accb` 为参考：入口 `|T|+|S|` 同比缩放，低纵向请求的转向范围按非对称域约束，非零 MIN 先于 EXPO，左右换向分别计时。允许急转内轮反转，不实施同向弧线限制。既有 `1e-6` 零阈值防止舍入残差触发 MIN，E 域 EXPO 映射保留本地冻结轮端包络。APM 百分比参数在此仍以既有归一化单位表达，不改变存储参数单位。

`CalibrationBraking` 使用单次前向停车的a=(v0-v1)/(t1-t0)，速度与时间来自有效RTK速度历元。首次跨零按两点线性插值，未跨零但进入原停速带时使用实测末速；后续回摆不进入前向距离/时间。首轮辨识响应，第二轮冻结候选验证，最终采用第二轮实测减速度，不混合不同动作平均、不扣标准差、不乘折扣。距离采用截至首次前向终点的速度积分与定位投影最大值，独立于减速度公式。500ms停稳窗只确认最终撤力/停稳；响应增益使用实际输入的J/Q加权，不含零输出等待。共享停车预算在名义距离外加入v*max(MOT_REV_DELAY, 本轮实测首次双轮反向等待)，纯滑停不加换向预算；这是保守留距，不是实测停车位移。定位与GPS链路余量由原围栏负责。

全输出试验使用冻结输出包络；正式制动只在后端确认满输出持续超过3秒后开始，不要求速度或加速度稳态。首轮反向响应用于辨识，第二轮持续反向则在停稳后拒绝候选；后端真实撤力与原安全边界保留。


公式修正：TransientSlope::measured_rate返回速度-时间回归斜率的绝对值，样本数、有效历元及非零激励决定能否求解，但不从结果扣置信边界；MotorResponseProfile::measured_speed返回有效平台最大均值。正式停车的平均减速度与停车距离独立存储：前者取第二轮验证后的Δv/Δt，后者保留各次实测距离最大值及速度覆盖范围。没有有效观测时返回NaN，消费者明确停车/拒绝，不用比较NaN的假分支继续运动。几何初探接口只保留真实执行的全输出有界试验，移除退役低速探测的3σ速度地板和假定目标。
