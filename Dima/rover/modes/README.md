## 运行契约

当前合同（2026-09-23 用户确认，以下历史描述有冲突时以本段及对应源码为准）：

- 模式不处理 PWM 脉宽、通道 REV 或左右电机输出映射。闭环转向比较 `rover_control_status` 中实际采用的物理角速度目标和反馈，开环只检查实验指定方向与物理响应；纵向/转向拟合消费该消息的执行轴，不再订阅 `actuator_motors` 自行反算轮端均值/差分。`actuator_output_status` 仅保留真实停波、制动时序和磁补偿等所需的后端执行证据，不用于产生或翻转运动方向。
- 首次运动不以偏航 PID 参数就绪为前提。掉头、转圈和返程对准在机动入口选择通路：本轮内环已经验证且已有偏航控制器能覆盖到位前的最小目标时使用现有 MODE_SPEED_YAW_RATE；初始辨识沿用校准的归一化开环激励，按 PROFILE 同样的 0.04/s 起步、确认起转后保持输入采样。机动期间不换通路，不积分角速度误差、不注入临时增益、不修改 REV。现有机动截止、RTK/IMU、角速度、围栏和执行器安全链继续生效。正式 PI 候选验证仍必须使用参数已应用的共用控制器。

- **响应子状态：** 每个 FWD/CW/CCW 分为 PROBE→RAMP→SETTLE→COLLECT→BRAKE。起步后保持请求并稳定 0.5 s；每档到位后连续稳定 1 s，收集至少 10 点且覆盖 1.2 s 才换档。窗口预算由实际 slew 推导，每个响应运动最多 90 s、保留最终 15 s 停车，全场仍不超过 600 s。CW/CCW 使用杆臂转动空间，不要求五米直线。

- **诊断与状态图：** 周期日志仅在选中自动校准且会话活动时输出，携带 session、skipped/unavailable、采集子状态和证据快照；退出或结束后停止重报旧阶段/故障，finish 单次报告结果，状态 Topic 保留终态。取消后的参数回滚和停波互锁仍继续收尾，不能随日志停止而解除。详细转移、超时和授权见 [当前状态机](../../../docs/AUTO_CALIBRATION_STATE_MACHINE_ZH.md)。
- **统一 IMU 零偏：** 复用 EKF 稳定偏置和 VehicleImu 实际校正快照，提交合格 ID/offset，保留 scale；重新确认前端、EKF 与残差后保存。组合会话暂停独立 IMU 后台写回，`EKF2_MAG_DECL` 仍只更新 volatile RAM。

## 头文件实现边界

模式状态访问器与校准事务构造/访问器统一在对应源文件实现；本轮没有合并不同阶段的终态、回滚或稳定窗口策略。 统一审查与验收见 docs/HEADER_IMPLEMENTATION_SPLIT_ZH.md。

- **主动制动测量：** 内联制动观测挂在 `STATE_STRAIGHT` 的 `Braking` 子状态，只有两轮同口径正式观测（`braking_run`=1/2），每轮使用有效速度历元和真实停波确认，首轮倒退用于响应辨识，第二轮持续倒退则拒绝（`braking_phase` 的 ACTIVE/SETTLE 与 `braking_model_generation` 合同不变）。空间/时间预算耗尽仍未进带时按当前前向速度直接制动观测（低于可观测地板则报 `FAILURE_DECELERATION`），纯滑停只有后端完整输出证据、真实停车及第二轮验证成立时才允许g=0。每轮停车由 `WaitStop` 子状态逐代确认控制器 RAM 模型后恢复直行开始下一轮；经第二轮固定候选验证的结果经 `TransactionKind::Dynamics`（WaitStop 的 Braking 意图，在第二轮完成且减速度尚未确认时提交）消费者/保存确认后标记独立 `STAGE_DECELERATION`，后续失败保留该成果；保存失败进统一回滚并报告 `FAILURE_STORAGE`。瞬时反向轮端输出不是倒退校准。
- **事务与辨识准备职责：** MagneticMotor已核对补偿系数代次/值及应用后新磁样本，不再空等2秒；Runtime只确认关联参数消费者，不重复要求停车/RTK融合。begin_identification仅校验配置并初始化实验，删除实时融合和旧PROFILE旋转语义下的围栏预检查；唯一后继IDENTIFICATION.WaitArm统一在正确直线语义下检查融合、停车、估计器、围栏并授权运动。运行期与采样质量检查保留，RTK/磁偏置的真实融合/残差观测窗保留。
- **动力学事务交接：** 减速度和速度/转向模型完成观测后，参数事务以真实消费者的同代同值确认推进，删除应用成功后无新增证据的固定2秒等待；保留参数匹配、代次更新、维护锁、回滚与FINALIZE统一保存。
- **制动约束归属：** J/Q连续输出历史仅为首轮增益辨识的必需证据；第二轮冻结g，不再因冲量历史缺帧否决，仍要求有效速度历元、无持续反向、后端零输出及500ms停稳，可用历史只补充输出等待。停车距离仅作诊断，不作为Δv/Δt模型的额外准入。WaitStop保留SETTLE时复用制动停稳判据，不重新附加角速度门；真实停波和模型ACK仍必需，其他静态/掉头等待保持原stopped语义。
- **制动观测预算：** 首轮使用去程90秒总预算的剩余时间，删除独立15秒制动截止且切入Braking不续期；第二轮在清空首轮J/Q之前冻结预算，取15秒与“按实测T_eff和本次初速预测到0.08m/s的分段停车时间 + 换向/后端等待 + 配置slew建立时间 + 原0.6秒速度历元留时 + 原0.5秒停稳窗”的较大值。纯滑停用首轮平均减速度估计时间，不计算1/g。等待不会自动续期；失鲜撤力、围栏、后端零输出和连续停稳证据不变。
- **制动探测起步：** 首轮未知响应时，执行层从零以0.15/s渐进输入，再乘clamp(v/v_entry,0,1)随剩余前向速度减弱反向力，受冻结E包络限制；实际轮端通过Brake线性映射，跳过驱动起步补偿。首轮实测候选确认后，第二轮和普通停车使用同一个冻结响应增益，不再固定0.5比例/0.30幅值，也不增加脉冲计时和重试轮次。
- **起步方向诊断：** 制动初探的航向/转速越界报告 `FAILURE_MOTION_ENVELOPE`，不再归为尚未测量的减速度失败。若仍无可观测平移，另外提示检查单侧 `PWM_Sx_REV` 与 RC 功能映射；Manual 某个杆位可以直行并不证明程序的双正向电机命令能直行。固件不根据该提示自动反转电机、交换遥控轴或放宽保护，安装方向与操纵轴须分别校正。
- **Level 提交持久化失败：** `STATE_PREFLIGHT` 内 `TransactionKind::Level` 的 20 s 保存窗内 `param_save_default` 持续不可用（典型为参数 Flash 分区满）报告 `FAILURE_STORAGE`，并在文本中携带最后 errno；此时 Level 结果仅在 RAM 生效、掉电即丢，不属于参数代次被外部改写的 `FAILURE_PARAMETER`。分区满的恢复动作固定发生在该事务的显式保存里（后台 autosave 满区即挂起、永不擦除）：SD 先提交当前 RAM 快照的同代副本，再整区擦除并回写，掉电不丢参数；重建成功后继续会话并唤醒 autosave。失败重试按 1 s 限流（避免 50 Hz 敲打与 logger 共享的 FatFs），`param:` 存储错误文本用于区分 SD 镜像与擦除分支；恢复后须重跑校准。

## AutoCalibrationMode 调度合同（权威正文）

2026-09-22 起本节是 `auto_calibration/AutoCalibrationMode.hpp` 的合同正文载体：头文件只保留
声明与定义和 5 行指针，此处正文与代码同步维护。实现分布：调度主链与唯一跳转点在
`AutoCalibrationMode.cpp`；统一事务机在 `AutoCalibrationTransactions.cpp`；测量/安全门谓词在
`AutoCalibrationGates.cpp`；FINALIZE 族在 `AutoCalibrationFinalize.cpp`；组调度器在
`AutoCalibrationGroupScheduler.cpp`；诊断发布（request/publish/report_status）在
`AutoCalibrationDiagnostics.cpp`。

### 状态压平与唯一跳转点

- `status_.state` 只表达 `AutoCalibrationStatus.msg` 的 11 个顶层阶段；阶段内的 Arm 等待、掉头、
  返程、制动观测、停车确认与事务推进由 `SessionController` 集中维护。任何代码（含阶段文件）不得
  再用 `status_.state` 判断事务类型或子状态；所有状态跳转（`enter_phase()`/`enter_substate()`）
  只存在于 `AutoCalibrationMode.cpp`。
- 顶层阶段的唯一存储为 `status_.state`，常量直接来自正式生成的 `Status::STATE_*`；
  `enter_phase()` 是阶段切换的唯一写入点，不另设内部阶段枚举、镜像字段或转换列表。
- `PhaseSubstate`：`WaitArm`（统一 Arm gate：条件
  齐备后等待人工 Arm，授权只属于 Commander）、`Running`（运动或采集进行中，是否发布运动意图见
  `is_motion_state()`）、`TurnAround`（直线族掉头子状态）、`Return`（返程子状态：按入场 GNSS 点
  返回；STRAIGHT的有效直行窗口保留返程标定采样，重对准/停车不采样）、`Braking`（内联制动观测：有界比例反向制动，瞬时反向轮端输出不是
  倒退校准）、`WaitStop`（真实停波确认：`stopped()` + 后端 maintenance 停波证据）、`Evaluate`
  （静态准备与事务机：Level前准备、候选计算、事务推进、组调度分发）。
- `TransactionKind`（None/Level/Rtk/Dynamics/Magnetic/MagneticMotor/Imu/Runtime/Gains）是事务类型的唯一判据；进度直接读取 `CalibrationParameters::Phase`。
  内环、航向、转驱和路径均使用 Gains 事务，共用 `step_validation()` 启动与停车。
  Flash 写入只发生在 FINALIZE 的 session_save/rollback。
- `StepResult` 是阶段 helper 的统一返回值，阶段文件只向调度器返回结果、绝不自行改状态：
  `Busy`（子状态未完成）、`Advance`（子状态完成，调度器推进）、`Evaluate`（helper 已发出/修订
  事务，请求进入事务评估子状态）、`WantTurn`（进入掉头，`session_.resume_substate` 已由 helper 填好）、
  `WantBrake`（进入内联制动观测）、`WantReturn`（进入返程，`resume_*` 已填好）、`WantStop`（进入
  真实停波确认）、`Failed`（实验组失败：先经 `fail_step()` 登记，调度器停车回滚后继续
  组调度）、`Abort`（会话级失败：登记后调度器直接 terminate）。
- 组合校准只发布运动意图和 Commander 请求。低优先级队列负责参数/文本及固定内存拟合；100 Hz 差速
  层和 PWM 后端独立执行失鲜与限幅保护。
- 输出包络 = 入场冻结的 `MOT_THR_MAX`（手动对等）：纵向 `[0,E]`、转向 `[-1,1]` 均无静态校准上限，
  运动由调度器输出包络、到顶后 8 s 无运动检查、围栏与
  slew 约束。`kIntervalUs`（10 ms）：校准请求与控制反馈使用同一 100 Hz 时间基准，避免 50 Hz 状态
  发布在制动接管和请求有效性判断中形成跨 Topic 半拍窗口。二维 RAM 路径内部期望尺度
  `kPreferredStraightDistanceM`；直线阶段单独使用 `RO_CAL_DIST`。
- `StopIntent` 是 WaitStop 子状态的出口目的（调度器内部；阶段文件不读写）：`None`、
  `Braking`、`RtkCommit`；Braking的提交/恢复分支由现有观测计数及减速度确认位决定。

### SessionController 字段合同

`substate`/`kind`由主调度与事务/组调度统一维护；
阶段 helper 允许写 `resume_substate`/`turn_direction`/`straight_outward`/
`turn_round` 这些"意图"字段，作为 WantTurn/WantReturn/WantBrake 返回的附件。事务类型判断一律读
`kind`，不得读 `status_.state`。`transaction_stages` 是事务关联 STAGE 掩码（前端确认路由/完成位，
代替旧 state 判别）；`substate_started` 是子状态入口时刻（Arm/停车/事务窗口基准）；
`turn_direction` +1=CW / -1=CCW；`turn_round`
1=动力学+磁覆盖、2=bootstrap 后残差学习；`force_rollback`（Level 失败等：FINALIZE 必须回滚）、

### 阶段 helper 接口约定（AutoCalibrationMode.cpp 之外的阶段文件必须遵守）

1. 阶段文件只导出四类函数：纯算法（无副作用、const）／采样（累计与滤波，写运动意图
   `longitudinal_`/`steering_`/`physical_speed_`/`physical_rate_`）／前端确认（const，供调度器
   事务机路由）／事务操作（begin_*/apply_*/finalize_*，只操作 `transaction_`，不改会话状态）。
2. 阶段文件不得调用 `enter_phase()`/`enter_substate()`/`terminate()`/`finish()`，不得写
   `status_.state`/`status_.result`/`active`/`motion_allowed`/`arming_allowed`，也不得用
   `status_.state` 判断事务类型（用 `session_.kind`）。所有状态跳转只发生在
   `AutoCalibrationMode.cpp`。
3. 失败统一上抛：`fail_step(reason)`/`abort_step(reason)` 登记原因并返回 `StepResult::Failed`
   （实验组失败：调度器停车→回滚→组调度器继续）或 `StepResult::Abort`（会话级失败：调度器
   terminate）。组自身的 unavailable/skipped/completed 位与诊断字段允许 helper 直接登记。
4. 意图声明：WantTurn/WantBrake/WantReturn/WantStop/Evaluate 由调度器映射为子状态推进；
   TurnAround/Return 的恢复子状态由 helper 预先写入 `session_.resume_substate`，
   Return 的闭环标志/请求清零快照、固定方向和截止起点由统一分发入口调用 `return_prepare(now)` 完成。WaitArm
   入口由调度器在阶段推进/事务确认时进入，不经 helper 返回值表达。
5. 直线族包络归调度器：`straight_leg`/`return_step` 只输出阶梯目标与起步下界的原始纵向/转向
   意图，不得自带预测速度限流、0.90 制动或 8 s 无运动门（`apply_straight_envelope` 统一执行）；
   Braking 子状态内的有界反向命令不受 `[0,E]` 包络约束。

### 统一 Arm gate 与会话复位

- `step_wait_arm(now)` 集中检查各运动面的测量条件并等待本轮人工授权，不按会话时长拒绝后续实验。
- `begin()` 清空状态/结果，复位动力学、磁/IMU 数据并持有会话存储锁，再从 Preflight 开始。
- 本轮掉头/返程恢复点只存在于 SessionController，新会话重置；入场圆心本轮不再移动。

### 安全不变量（不得削弱）

- Arm 边界：授权只来自 Commander 真实 Armed 边沿（`service_motion_authorization` 仅镜像诊断）；
  运动前必须 `start_motion()` 确认授权、投影收敛并释放停波锁。
- 真实停波：不能用"命令为零"代替后端停波确认（`maintenance_ready()` = `calibration_output_
  stopped()`），该锁保持到维护/写入完全结束。
- 时间窗：保留 300 ms 质量失败确认、15 s 停车、20 s 参数前端确认及各实验自身观察/不收敛窗口；没有会话总截止和后续阶段累计时间门。等待中持续失鲜或估计器参考失效复用300ms确认窗退出，正常等待人工授权不超时。
- 包络：全局速度上限是用户巡航速度；轮端输出、yaw-rate、围栏/停车空间仍由现有执行与安全链约束。
- provisional 不越权：RAM 候选只有经前端代次确认并最终保存后才转入 completed；
  `provisional_validated_stages` 不冒充完成。前端代次确认（`transaction_frontend_confirmed`）
  按 kind/stages 路由，不读 `status_.state`。
- FAILURE_STORAGE 不降级：最终保存失败或回滚无法确认保留 Fault 互锁；不自动重试保存，也不伪造完成位。
- 统一保存合同：会话期间持暂停锁；FINALIZE 持锁保存一次，成功后释放。已被显式保存清空的 dirty 位不再触发积压 autosave，介质修复走独立强制请求。

### 实验判据删减（2026-09-23）

- 平台：保留输入到位/保持、有效样本和有界窗口；删除固定加速度及 COLLECT 的逐帧噪声倍数门，候选效果由后续辨识/验证确认。过渡斜率只看变化量的可观测性，不重复限制两端绝对幅值。
- 噪声：保留静止准入、5 s/50 样本与有限正噪声；不再用速度均值 3σ 或角速度均值 0.03 rad/s 额外拒绝噪声估计。
- 制动：保留有限正减速度、距离/时间上界，首轮倒退用于响应辨识，第二轮持续倒退则拒绝；最终采用第二轮实测值，不取min或人为折扣。停车完成统一为 0.08 m/s 加后端零输出、连续 0.5 s，不叠加 0.05 m/s 完成门。
- 验证：使用已有10%阶跃误差目标，不叠加死区/噪声倍数和30%可行性上界。验证器的最终样本窗负责稳态误差，不再额外累计内环1 s、Heading 1.5 s模式层等待；退出仍检查当前输出未被遮蔽，Heading 保留用户退出角和低角速条件。

### 大阶段内部子流程精简（2026-09-23）

- PREFLIGHT：Level worker 成功后在同一分支核对参数计数、接收候选并检查动态配置，删除独立 Evaluate 中转。
- BASELINE/STRAIGHT：直接进入 Running；首段直行已通过 arm_gate/start_motion，不再经过会重新锁 PWM 的空 Entry。
- MAGNETIC：直接进入 Evaluate；正常候选与首次 bootstrap 共用应用入口，路径不可用与拟合不收敛共用恢复入口。bootstrap 次数与前端确认保留。
- PROFILE：IMU 事务使用 Evaluate；响应准备完成后直接 WaitArm。IDENTIFICATION、VALIDATION、NAVIGATION 在准备/事务确认后直接进入所需子状态，删除备用 Entry 初始化。
- Return 与 WaitStop：在既有 step() 统一处理。Return 保留 STRAIGHT 特有包络；WaitStop 保留15 s、真实停车/停波、组回滚。FINALIZE 的终态 WaitStop 不进入运动停车检查。
- enter_phase(target, now, initial) 一次进入有效子状态；只有 start_motion 可以解除输出抑制。公开11阶段、双向观测、实验算法、参数定义与人工一次Arm流程不变。

### 自动校准范围与保存语义（2026-09-23）

- 自动模式只请求 Level worker；磁 offset 使用双向转动观测，IMU offset 使用 EKF bias。没有六面翻转或六面拟合调用，ID/scale/rotation 不由自动模式改写。手动传感器校准模块的六面流程属于独立入口。
- PROFILE 在三种运动面完成后进入 Evaluate 轮询 Runtime 事务；Provisional 确认后准备 IDENTIFICATION，不再重复执行 WaitStop 的序号递增和候选建立。
- provisional_validated_stages 表示本会话 RAM 已确认的证据，并用于运动/实验依赖。completed_stages 在运行中为0，仅在 FINALIZE 最终保存成功后设置。缺设备记 skipped，不把 MAG_SKIPPED 混进完成位。
- 阶段回滚确认返回 Failed，表示候选失败、旧值已恢复；绝不按 Done 登记新候选成功。回滚同步自有参数计数，关联 Runtime/PI/导航事务整体回滚时清除其局部验证证据。
- 取消和正常收尾都由 FINALIZE 关闭活动 worker/候选事务，进入该阶段后不再接受新的Arm授权。会话恢复按生成依赖先写源校正、后写观测身份；所有权冲突或写入失败锁存Fault，不能超时后宣称恢复完成。
- 终态完成位只来自成功保存的有效证据，回滚/存储失败不保留完成位；导航可选项逐位核对，某一项跳过不覆盖其余未知或失败项。

### 子流程必要性复核（2026-09-23）

- 保留独立职责：Evaluate同时负责Level请求前静态准备；WaitArm 负责已有授权下的运动准入；Running 执行实验；Braking 负责有界反向制动；TurnAround/Return 分别负责方向切换与固定点返场；WaitStop 确认真实停车；Evaluate 推进候选与前端确认。
- 删除 TURN 的额外重融合 Entry（3 s 稳定等待、30 s 独立截止）：前一笔 RTK/磁事务已验证融合，TURN 直接 WaitArm，仍逐周期检查融合，不设人工等待/累计会话时间截止。
- PROFILE 的 IMU 事务并入 Evaluate，与 Runtime 共用事务轮询；删除专用 Entry 分支。
- FINALIZE 直接等待Disarm/worker/候选回滚、作一次决策、推进保存/回滚并发布结果；删除发布中转、终态WaitStop、finalize_published和SessionSave/SessionRollback镜像类型。active=false保证终态不重复发布。
- 条件性实验不是每轮必做：磁bootstrap第二轮仅在需要初始化时执行；验证修复最多两次且需实际空间；路径额外候选按可观测变化选择。双方向观测、非零下降验证仍为当前模型的证据来源。
- 参数范围、无六面校准、offset-only、一次人工Arm及取消语义不变。运行中保持RAM证据与最终保存位分离。
